RAPPORT - VALIDATION EXPLORATOIRE EXTERNE SUR LE CORPUS MCGILL
Date : 2026-04-16

1. Objectif

L'objectif de cette étude était d'appliquer le pipeline gelé du mémoire
(Isolation Forest + règles métier) sur un corpus externe issu des données
McGill (Fall 2019), afin d'évaluer :

- la transférabilité technique du pipeline vers un second corpus ;
- l'existence éventuelle d'un signal cohérent avec les scores cliniques SLS
  historiques disponibles ;
- la possibilité d'utiliser ce corpus comme validation externe partielle
  pour le projet personnel.

- boiteuse_stricte : au moins un score SLS >= 2 ;

- sans_score : aucune information SLS disponible.

6. Lecture scientifique honnête

Cette étude montre clairement que :

1. le pipeline du mémoire est portable techniquement vers un corpus externe ;
2. il peut être exécuté sans modification de fond sur les données McGill
   converties au même format ;
3. certaines vaches historiquement boiteuses produisent bien des alertes ;
4. mais la comparaison aux labels historiques ne permet pas de démontrer une
   validation clinique externe nette.

La raison principale est le décalage temporel entre :
- les labels SLS (janvier-mars 2019),
- les signaux IceTag utilisés (novembre-décembre 2019).

En conséquence, ce test ne doit pas être présenté comme :
- une validation clinique,
- ni une preuve de généralisation clinique.

Il peut en revanche être présenté comme :
- une validation exploratoire externe ;
- une démonstration de transférabilité technique ;
- un test préliminaire utile pour orienter les analyses futures sur le corpus McGill.


7. Ce qu'on peut dire dans le mémoire ou un rapport

Formulation recommandée :

"Une application exploratoire du pipeline sur un corpus externe McGill a confirmé
la transférabilité technique du système à un second jeu de données accélérométriques.
En revanche, la comparaison avec les scores cliniques SLS historiques n'a pas permis
de dégager une séparation nette entre animaux historiquement boiteux et sains,
notamment en raison du décalage temporel important entre les évaluations cliniques
et les données capteurs, ce qui empêche toute conclusion clinique forte."


8. Recommandations

Pour aller plus loin, les suites les plus utiles sont :

1. inspecter en détail la vache 5879 afin de comprendre pourquoi elle déclenche
   fortement malgré un historique sain ;
2. comparer 5879 avec 821 et 3444 au niveau journalier et au niveau des épisodes ;
3. tester si certaines règles métier sont trop permissives sur ce corpus externe ;
4. si des labels cliniques synchrones deviennent disponibles, relancer le pipeline
   sur cette nouvelle base pour une validation externe plus crédible ;
5. utiliser ce corpus surtout comme base de travail du projet McGill plutôt que
   comme preuve clinique pour le mémoire personnel.


9. Conclusion

L'étude est utile et doit être conservée, mais son message doit rester prudent :

- réussite technique : OUI
- transférabilité du pipeline : OUI
- validation clinique externe forte : NON
- intérêt méthodologique pour le projet McGill : OUI

Le résultat le plus honnête est donc le suivant :
ce corpus McGill apporte une valeur réelle comme test externe exploratoire et comme
point d'entrée pour un projet de recherche complémentaire, mais il ne suffit pas à
renforcer seul la validité clinique du mémoire principal.
