# Projet McGill - IoT Bovins Laitiers

Collaboration avec Dr. Elsa Vasseur (McGill) sur l'analyse de données IoT
pour bovins laitiers en stabulation entravée.

## Équipe
- **Elsa Vasseur** (PI, McGill) — conceptualisation, supervision
- **Tania Wolfe** (McGill) — collecte et préparation des données
- **Marjorie Cellier** (McGill) — analyse accéléromètres, auteure principale article de référence
- **Abdoulaye Diallo** (UQAM) — lien académique
- **Aliou Barry** (UQAM) — analyse de données, développement notebook IoT

## Objectifs
1. Analyser l'impact des données environnementales (température, humidité) sur le comportement des vaches (accéléromètres sur pattes)
2. Intégrer des données comportementales observationnelles dans les modèles
3. Développer un Notebook Jupyter pour l'utilisation d'IoT en bovins laitiers

## Données
- Expériences menées entre 2018 et 2023
- Sources : accéléromètres (pattes), capteurs environnementaux, observations comportementales
- En attente de réception via Tania Wolfe
